# FretDance 插件使用说明书

## 简介

FretDance 是一个为 Blender 开发的吉他演奏动画生成插件，专门用于创建逼真的吉他演奏动画。该插件支持手指弹奏吉他、电吉他和贝斯等多种乐器类型，能够控制左手按弦和右手拨弦的动作。

## 安装与初始化

### 插件安装

1. 在 Blender 中打开 `编辑 > 首选项 > 插件`
2. 点击"安装"并选择插件文件
3. 启用"FretDance Controller Setup"插件

### 初始设置

1. 在 3D 视图中打开右侧边栏，选择"FretDance"选项卡
2. 在"初始化"区域：
   - 选择乐器类型（指弹吉他/电吉他/贝斯）
   - 点击"检查状态"检查当前控制器状态
   - 点击"设置控制与记录器"创建必要的控制器对象
   - 如使用 MMD 模型，点击"初始化 mmd 骨骼"进行骨骼适配

## 主要功能模块

### 1. 左手状态控制

在"选择左手状态"区域设置左手姿势：

- **Position（位置）**：选择基础手位（P0-P4）
- **State（状态）**：选择按弦方式
  - Normal（普通按弦）
  - Outer（外侧按弦）
  - Inner（内侧按弦）
  - Barre（横按）

### 2. 右手状态控制

在"选择右手状态"区域设置右手姿势：

- **State（状态）**：选择右手位置
  - Low（低位。如果是电吉他，就是匹克演奏第 6 弦的状态；如果是指弹吉他，就是大拇指在第 6 弦的演奏状态；如果是贝斯，就是演奏第 4 弦的状态）
  - End（扫弦结束位置）
  - High（高位，如果是电吉他，就是匹克演奏第 1 弦的演奏状态；如果是指弹吉他，就是大拇指在第 4 弦的演奏状态；如果是贝斯，就是演奏第 1 弦的状态）

### 3. 状态设置与加载

- **Set（设置）**：将当前控制器状态应用到记录器
- **Load（加载）**：从记录器加载状态到控制器

### 4. 导入/导出人物信息

- **导入**：从 JSON 文件导入整个人物的信息
- **导出**：将整个人物的信息导出为 JSON 文件

### 5. 动画生成

在"生成动画"区域制作演奏动画：

1. 点击"选择动画文件"选择动画配置 JSON 文件
2. 可分别生成：
   - 左手动画
   - 右手动画
   - 弦动画
   - 一键生成全部动画

## 使用流程

### 设置步骤

1. 初始化设置（选择乐器并创建控制器）
2. 设置左右手状态
3. 使用 Set 按钮保存状态

### 使用步骤

1. 使用 fretdance 生成演奏的 json 数据
2. 导入该 json 数据
3. 生成所需动画

### 动画配置文件格式

JSON 配置文件应包含以下字段：

```json
{
  "guitar_string_recorder_file": "弦动画数据文件路径",
  "left_hand_animation_file": "左手动画数据文件路径",
  "right_hand_animation_file": "右手动画数据文件路径"
}
```

## 注意事项

1. 使用前请确保已正确设置控制器对象
2. 动画配置文件中的路径需要正确指向实际存在的文件
3. 更改乐器类型后需要重新进行初始化
4. 生成新动画前会自动清除同类型的历史关键帧
5. 建议在生成动画前保存当前工作进度

## 故障排除

- 如果控制器无法正常工作，请使用"检查状态"功能，在 blender 的控制台窗口查看问题信息
- 如果 MMD 模型动画异常，请确保已点击"初始化 mmd 骨骼"
- 动画生成失败时，请检查配置文件路径是否正确以及文件是否存在

通过以上步骤，您可以使用 FretDance 插件创建专业的吉他演奏动画。建议初次使用时先尝试简单的单个动画生成，熟悉操作后再进行复杂动画制作。
